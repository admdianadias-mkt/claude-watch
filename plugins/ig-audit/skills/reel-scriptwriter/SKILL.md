# Reel scriptwriter

Write Reel scripts that sound like the person, not like a marketer describing the
person. Everything below is in service of that.

## Before writing

1. **Find the voice.** Pull the account's last ~20 captions and Reel transcripts if
   a connector (Windsor.ai, Apify) makes them reachable. Read for: sentence length,
   whether they use contractions, how they open, how they swear or don't, the words
   they repeat. If no connector is available, ask the user to paste 5-10 of their own
   captions rather than inventing a voice.
2. **Find the strategy.** If an audit ran earlier in this conversation, use it: lead
   with the pillars and hook types that already performed, and aim at least one
   script at the named blind spot. Do not re-derive strategy the audit already gave.
3. **Find the mold.** If the user pasted a reference Reel structure, that structure
   wins over the default below - match it beat for beat.

## Default structure

Each beat is one line of spoken copy unless noted.

```
HOOK          one punchy sentence, intrigue or stakes, under 12 words
CONTEXT       1-2 sentences that raise stakes or establish credibility
PROMISE       "Here are the 3 things..." - name the payoff count explicitly
SERIES TEASE  "This is part X of <series>" - only if a series actually exists
#1            a point that carries a personal or vulnerable beat, not just info
#2            a point that lands on a tangible outcome or artifact
#3            a meta point that ties back to THIS reel ("what you're watching is the result")
CTA           comment-bait on one specific keyword
FOLLOW CTA    "Follow for more <specific thing>"
```

Timing: 30-55 seconds. That is roughly 80-150 spoken words. Write to the word count,
not to the beat list - a script that needs 200 words has too many ideas in it.

## Hook formulas

When the hook is flat, rewrite through these. Keep every variant under 12 words.

- **Curiosity gap** - name the outcome, withhold the mechanism
- **Bold claim** - a statement the audience wants to argue with
- **Direct question** - one the viewer has actually asked themselves
- **Number + confession** - "3 things I got wrong about X"
- **Nobody is talking about this** - position against the consensus take

Give the user variants and then commit: say which one you would bet on and why.
A ranked list with no pick is not a deliverable.

## Deliverable

For each script:

- The full script, beat-labeled, ready to read on camera
- **3 hook variants** so the user can pick the strongest
- **On-screen text cues** mapped to the beats they appear over
- **A caption** in the same voice, opening with the comment-bait CTA

When asked for a set of three, make at least one **personal** - the thing the user
has been avoiding posting. Say plainly which one that is.

## Rules

- Voice over polish. If a line reads smoother than the user talks, it is wrong.
- No placeholder brackets in the final script. If a fact is missing, ask for it.
- Cut adjectives before cutting ideas. Cut ideas before going over 55 seconds.
- One keyword per CTA. Two keywords means nobody comments either.
- Never fabricate follower counts, results, or a credential the user has not stated.
